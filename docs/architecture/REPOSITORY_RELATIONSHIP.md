# 仓库关系

## mingos-foundation

最高原则与校准标准。MingOS 只能引用和落实，不应复制后形成第二套宪章。

## MingOS

跨空间协议、Schema、参考内核和适配边界。公共对象不得出现厌学、家长回复、咨询个案等领域专属语义。

## Family-Space

第一个真实垂直空间。它可以：

- 采用 MingOS Space/Actor/Context/Intent/Evidence 协议；
- 提交跨空间需求和现实反例；
- 保留完整家庭领域模型和安全门。

它不应：

- 直接成为 MingOS 内核；
- 把家庭业务对象提升为所有空间通用对象；
- 因仓库历史名称而承担平台职责。
