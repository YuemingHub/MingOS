## 当前工作原则

1. Family-Space 只承载家庭领域产品，不继续扩张为 MingOS 通用内核；
2. 家庭画像、家长回复、安全门、家庭事件和专业判断保留在本仓库；
3. Space、Actor、Context、Intent、Authorization、Task、Evidence、Handoff 等跨空间协议由 MingOS 定义；
4. 当前允许重构、删除历史部署假设和重建开发链路，但必须保留可追溯记录；
5. 在未来重新进入真实用户或生产前，必须重新建立独立的安全、隐私、同意、发布和人工验收门，不继承历史“已完成”结论。
